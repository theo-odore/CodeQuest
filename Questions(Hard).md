

# Phase 3 — Hard (Write Code)

Participants write complete Python programs in the code editor.
Each problem has equal marks.

---

## Q1. Reverse Words in a Sentence ⭐

Write a Python function `reverse_words(sentence)` that returns the sentence with the order of words reversed.

Example

Input:
```
CodeQuest is fun
```

Output:
```
fun is CodeQuest
```

---

## Q2. Prime Number Checker ⭐

Write a function `is_prime(n)` that returns `True` if the given number is prime; otherwise return `False`.

Example

Input:
```
17
```

Output:
```
True
```

## Q11. Valid Parentheses ⭐⭐⭐

```

Balanced

```

## Q15. Tic-Tac-Toe Winner ⭐⭐⭐⭐

Given a completed **3 × 3** Tic-Tac-Toe board, determine the winner.

The board contains only:
```
X
O
.
```

`.` represents an empty cell.

Print:

- `X Wins`
- `O Wins`
- `Draw`

Example

Input:
```
X O X
O X O
O X X
```

Output:
```
X Wins
```
